# nmarvis (牛马维斯)

> **赛博牛马，为你24小时随时在线搬砖。**

欢迎来到 `nmarvis` 组织！这是一个致力于为广大“牛马”量身定制的开源生态。如果说腾讯的 Marvis 是你的全能管家，那么 nmarvis 就是你的**最佳打工平替**和**赛博摸鱼掩护者**。

## 🐴 更懂牛马的 AI 助手

* **本地摸鱼大模型，老板 0 监控：**
    提供“奋斗模式”与“摸鱼模式”一键切换。在摸鱼模式下，所有数据本地处理，最大程度保护你的摸鱼隐私，不留一丝痕迹。
* **手机随时假装在工位：**
    支持手机直连工位电脑。无论你是在带薪拉屎还是在通勤地铁上，都能随时接管电脑鼠标晃动，为你打造随时随地都在“努力”的完美人设。
* **废话文学智能生成与润色：**
    深度理解职场生存法则。支持一键生成高情商回复、千字周报扩写、甩锅话术大全，让你的职场沟通（糊弄）效率蹭蹭提升。

## 💼 照顾你打工的方方面面

### 🗂️ 糊弄学大师
自动转换文件格式，一键生成毫无破绽的会议纪要，自动把别人的代码改成你的代码风格。

### 🎭 加班假象营造器
定时在深夜提交 Git Commit，自动在凌晨发送“收到”回复，精准拿捏职场表现分。

### 🎮 薪水小偷好搭子
限时福利监控、Steam 喜加一自动领取、带薪游戏时间智能规划。

## 🚀 快速开始 (假装有代码)

```bash
# 克隆牛马之魂
git clone [https://github.com/nmarvis/nmarvis.git](https://github.com/nmarvis/nmarvis.git)

# 启动摸鱼模式
cd nmarvis
npm run start --mode=moyu
```
