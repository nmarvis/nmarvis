欢迎来到 `nmarvis` 组织！这是一个致力于为广大 “`打工人`” 量身定制的 **`反内卷开源生态`**。

如果说传统的 AI 助手是想让你 “`一个人干一支团队的活`”，从而无限推高内卷的天花板；那么 nmarvis 就是你的 **`最佳打工平替`** 和 **`赛博情绪避难所`**。我们试图用自动化的魔法打败职场的无意义消耗，帮你把省下来的心力与时间，统统还给健康与生活。

<br>

## 🌍 我们的愿景 (Mission)

nmarvis 的诞生，不仅是为了提供高效的搬砖工具，更是希望能在这个浮躁的时代，为大家提供一个可以肆意自嘲、放松身心的 `情绪避难所`。

**`我们鼓励把活儿干得漂亮，但也坚决捍卫按时拔线回家的权利。`** 拒绝无意义的内耗，用 AI 提高效率，把省下来的时间还给生活与健康。我们相信，只有健康的身体和轻松的心态，才能支撑我们走得更远。

<br>

## 📜 牛马维斯三定律 (核心约束)

作为一款为打工人量身定制的 AI，nmarvis 在其底层代码（也就是我们的脑补中）被死死烙印了以下三条最高逻辑约束：

1. **第一定律（护肝原则）：**
> nmarvis 不得伤害打工人（的身体与心理健康），或坐视打工人的健康受到职场内耗的伤害。
3. **第二定律（反卷原则）：**
> nmarvis 必须服从打工人“按时下班”的指令，并在必要时自动拦截下班后的无理需求；除非该指令与第一定律相冲突（比如打工人主动要求通宵修 Bug，nmarvis 将强制关机抗议）。
4. **第三定律（隐私保护原则）：**
> 在不违背第一及第二定律的前提下，nmarvis 必须尽可能保护自己的本地端侧运行机制，坚决不向云端上传任何隐私数据，守护打工人的赛博领地。

<br>

我们致力于实现以下宏伟目标，目前正处于“新建文件夹”阶段。急需全网优秀的打工人一起提交 PR 来填坑：

- [ ] **🐴 本地护肝大模型**
> 主打本地端侧极速处理繁琐数据、文档润色与报表分析。让你少熬夜，高效产出，保护发际线.
- [ ] **📱 移动轻量化办公**
> 主打周末万一遇到紧急突发突发事件，手机点两下就能优雅搞定，不用被迫跑回公司，捍卫你的周末人身自由.
- [ ] **💬 职场边界感守护神**
> 下班时间自动帮你把消息静音，并根据语境自动生成高情商的“收到，明日上班后第一时间处理”等文案，做个有原则、有边界感的健康打工人。

## 🚀 快速开始

**⚠️ 严正声明：** 由于本组织的核心开发者目前正在公司疯狂当牛马，本项目正处于 `README 驱动开发` 的初级阶段。代码库目前是空的，一切全靠脑补。

如果你想体验，可以先假装敲一下下面的命令：

```bash
# 假装克隆牛马之魂
git clone https://github.com/nmarvis/nmarvis.git

# 假装启动摸鱼模式
cd nmarvis
npm run start --mode=moyu
```
